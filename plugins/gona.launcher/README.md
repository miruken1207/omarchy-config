# Gona Launcher — my config

**Original plugin:** [Gona Launcher](https://github.com/Mgldvd/gona-launcher)
by **Mgldvd**. The plugin code is not modified and not stored here; it is
installed from its upstream repository. This directory only holds my own
settings file, `config.toml` (installed to `~/.config/gona-launcher/config.toml`).

Tested with v1.0.2. Opens with `SUPER + TAB` (see [`bindings/`](../../bindings/)).

## What is customized

**Look** — a frosted-glass full-screen launcher:

- Full-screen mode, `beams` open effect (550 ms).
- Translucent background: `#0b0f14` (dark) / `#eff1f5` (light) at 60% opacity;
  colours otherwise follow the active Omarchy theme.
- No tile background (`appBg = none`): icons sit directly on the glass.
- 40 px icons without names.
- Bottom button strip (all apps, power, profiles) and the "most used" row are off.

**Tiles** — 27 pinned apps: Firefox, Yandex Browser, Chromium, YouTube, Twitch,
Gmail, GitHub, Kinopoisk, Yandex Pochta, Yandex Disk, Telemost, Yandex Music,
Telegram, MAX, Zed, PyCharm, GoLand, Claude, Happ, Obsidian, OBS Studio,
LibreOffice (start center, Calc, Base, Draw), Flea, Syncthing.

Search covers all installed apps, sorted by how often they are used.

## Requirements

- **Blur (glass effect).** The translucent background only looks like frosted
  glass with Hyprland blur, which Omarchy turns off by default. It is enabled in
  `~/.config/hypr/looknfeel.lua`:

  ```lua
  hl.config({ decoration = { blur = { enabled = true, size = 10, passes = 3, noise = 0.02, brightness = 1.0 } } })
  hl.layer_rule({ match = { namespace = "^gona-launcher$" }, blur = true, ignore_alpha = 0.05 })
  ```

- **A tile only shows if its `.desktop` file exists.** Tiles are listed by
  desktop id, so the apps must be installed, and the web apps (YouTube, Twitch,
  Gmail, GitHub, Kinopoisk, Yandex Pochta, Yandex Disk, Telemost, MAX,
  Syncthing) and Claude need their `.desktop` files in
  `~/.local/share/applications/`.
- **PyCharm and GoLand** ids contain a UUID generated by JetBrains Toolbox
  (`jetbrains-pycharm-78000a09-…`). After a reinstall Toolbox creates new ids,
  so re-pin these two tiles from the launcher.

## Install

```bash
~/omarchy-config/plugins/gona.launcher/install.sh
```

Adds the plugin with `omarchy plugin add` if it is missing and restores
`config.toml`, backing up an existing one as `config.toml.bak.<timestamp>`.

## Save changes

The launcher writes this file itself when you change settings or tiles in its UI.

```bash
~/omarchy-config/plugins/gona.launcher/save.sh
```
